# Tipografia

Nunito Sans (400, 700 e 800), empacotada localmente pela dependência `@expo-google-fonts/nunito-sans` e carregada em `App.tsx` por `expo-font`. O aplicativo não baixa fontes em tempo de execução. Os arquivos originais e a licença OFL ficam na dependência e são incluídos pelo bundler.

Fonte: https://github.com/google/fonts/tree/main/ofl/nunitosans (SIL Open Font License 1.1).
